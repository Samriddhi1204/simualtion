# Homework Platform: Problems and Fixes Simulator

A single-page dashboard where you cause each system problem yourself, watch it break, then switch the fix on and watch it work.

## Open it

Open `index.html` in a browser. It works straight from disk and from GitHub Pages.

## What is inside

- Overview page with a diagram of the platform and the six problems pinned to it
- Q1 to Q6 demos and Q7 with five smaller problems
- A live log panel that every demo writes to
- A guided tour that walks through every demo

All numbers used inside the animations are illustrative.

## Privacy

The page is fully offline and collects nothing. It has no dependencies, no network calls, no analytics, no cookies and no local storage.
